# Audio Ads Studio

Home Assistant add-on per creare spot pubblicitari in stile radiofonico con voce AI, musica, effetti e mastering.

## Funzioni principali

- TTS neurale multilingua
- voci femminili e maschili
- tedesco, italiano, inglese, rumeno, francese e spagnolo
- regolazione velocità, tono e volume
- libreria musica ed effetti
- libreria starter generata al primo avvio
- ducking automatico della musica sotto la voce
- intro e outro
- preset Streaming, Radio EBU e Sonos
- esportazione MP3 e WAV
- archivio spot
- interfaccia Home Assistant Ingress per telefono e PC

## Installazione

Aggiungi questo repository allo Store di Home Assistant:

https://github.com/EdisonACDC/audio-ads

Poi installa **Audio Ads Studio**.

## Motore voce

La versione 1.0 usa Edge TTS. È necessario che Home Assistant abbia accesso a Internet durante la generazione della voce.
